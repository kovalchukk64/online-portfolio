# Онлайн-портфоліо розробника

Особистий веб-сайт портфоліо студентки групи П-31 Гусятинського фахового коледжу ТНТУ імені Івана Пулюя Ковальчук Софії.

## Використані технології
- HTML5 (семантична розмітка)
- CSS3 (Flexbox, CSS Grid, адаптивний дизайн)
- JavaScript ES6+
- Git & GitHub (контроль версій, гілкування, злиття)
- GitHub Actions (CI/CD автоматизація деплою)
- GitHub Pages (веб-хостинг)
